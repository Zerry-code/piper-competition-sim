# Sim2Real 仿真迁移准备与验证报告

Sim2Real（Simulation to Reality）是将仿真中开发或训练的感知、规划和控制方法迁移到真实设备，处理理想模型与真实传感器、接触、执行之间的差异。当前属于传统视觉＋IK＋闭环技能的迁移准备，没有训练新的抓取策略，也没有进行真机验证。

## 修改内容

| 针对的问题 | 本次修改 | 主要位置 |
|---|---|---|
| 理想相机与真实深度不同 | 提供噪声、缺失像素、固定深度尺度偏差 | config/sim2real.yaml、src/piper_sim/sim2real.py、backend.py |
| 相机安装与标定不一致 | 扰动实际渲染相机的位置和旋转，控制器保留原名义手眼标定；不把真实扰动值用于视觉坐标修正 | sim2real.py、competition_world.py |
| 质量和摩擦不确定 | 按物品采样质量及滑动摩擦倍率；惯量随质量同步缩放，显式接触对的滑动摩擦也同步变化 | sim2real.py |
| 真实指令存在执行延迟 | 用有序指令队列引入0/1/2控制周期延迟，不跳关节、不瞬移物品 | backend.py、sim2real.py |
| 完成判定依赖仿真物体真值 | 释放后重新采集RGB-D，确认同类别目标在指定卡纸内连续稳定；看不到或证据不足保持未确认并进入恢复。物理真值仅作独立评估 | scripts/run_harvest.py |
| 无法比较、复现误差实验 | 增加网页误差档位；同种子可复现采样。每个场景保存deployment-gap.json，网页详情可查看参数 | scripts/web_console.py、assets/ui/task_console.html |
| 后续接硬件的接口约定 | 补充RobotPort协议，沿用Observation传感器数据与标准动作格式 | src/piper_sim/robot_port.py、已有observation.py及control.py |

已有随机摆放、质量区间、摩擦随机化保留，本次增加独立的可选择误差档位和可追溯采样记录。未改变水果外形来掩盖抓取问题，不焊接、冻结或瞬移物品。

## 参数与操作

网页Ctrl+F5刷新，右上选择档位后点击“随机重置”应用；运行中不可切换。当前服务保持基准档。

| 参数 | 基准 | 轻度迁移误差 | 压力测试 |
|---|---:|---:|---:|
| 深度噪声标准差 | 1毫米 | 2毫米 | 4毫米 |
| 深度缺失概率 | 0.5% | 1% | 3% |
| 深度尺度偏差范围 | 0 | ±0.2% | ±0.5% |
| 相机平移各轴范围 | 0 | ±2毫米 | ±5毫米 |
| 相机旋转各轴范围 | 0 | ±0.4度 | ±1度 |
| 质量倍率变化 | 0 | ±15% | ±30% |
| 滑动摩擦倍率变化 | 0 | ±15% | ±25% |
| 指令延迟（20Hz） | 0 | 50毫秒 | 100毫秒 |

这些是开发实验假设，不是实测大白相机或PiPER的指标。扰动每次场景生成时采样并保持，深度噪声逐帧产生。参数可在config/sim2real.yaml调整。单个成功试验不代表该范围内所有情况都通过。

## 验证结果

115项自动检查通过，包括种子复现、指令延迟顺序、名义标定保持不变，以及没有仿真物体真值时视觉判定仍能工作、目标不可见不能判成功。

## 当前边界与真机待办

没有完成真机Sim2Real，也没有成功率统计、训练新模型或覆盖全部随机布局。压力档暴露了视觉空位确认的误差敏感性。

视觉验证使用可见点云，遮挡会影响对完整物体轮廓的确认，不能等同于实物全轮廓认证。真实相机需要测量内参、深度尺度、手眼外参、时间同步和曝光；真实执行器需要测量延迟、跟踪误差、夹爪力与速度约束。

RobotPort是接口契约，现有Observation已支持同步传感器输入；当前IK、夹持接触反馈及部分控制逻辑仍访问MuJoCo，尚未完整移植到硬件适配器。真机需要用SDK/ROS或CAN状态反馈和实际抓取检测替换这些依赖，不能仅实现四个接口就直接驱动真机。
